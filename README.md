# 니케 지휘관 도우미

승리의 여신: 니케 개인용 팬 도구예요. 브라우저에서 바로 열면 돼요.

**바로 열기: https://gomdolski.github.io/nikke-helper/**

- 니케 도감 (추천 큐브, 오버로드 옵션, 스킬 레벨, 같이 쓰는 덱)
- 보유 니케 체크 (블라블라링크 시프티패드에서 한 번에 가져오기)
- 오버로드 옵션 판정, 하모니 큐브 추천
- 솔로 레이드 / 유니온 레이드 / 이상개체 요격전 덱 짜기
- 레벨업 재료 계산기

보유 목록은 각자 브라우저 안에만 저장되고, 어디에도 올라가지 않아요.
새 버전이 올라오면 페이지 위쪽에 알림이 떠요.

## 고치는 법

1. `build/` 안의 파일을 고쳐요 (`page.html` 화면, `raid_section.js` 덱 짜기, `*.json` 데이터).
2. `node build/build.js --note "바뀐 점"` 을 실행해요. `index.html`, `version.json` 이 새로 만들어져요.
3. 커밋하고 푸시하면 몇 분 안에 웹 주소에 반영돼요.
