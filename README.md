# 니케 지휘관 도우미

[승리의 여신: 니케](https://nikke-kr.com/)용 비공식 도우미입니다.

- 바로 열기: https://gomdolski.github.io/nikke-helper/
- 매주 금요일에 데이터 갱신 (목요일 패치 다음 날)

## 계정 연결

연결해 두면 보유 니케, 장비 옵션, 큐브, 스킬, 전투력이 자동으로 채워집니다. 처음 한 번만 하면 됩니다.

1. [ShiftyPad 숨김 설정](https://www.blablalink.com/setting/shiftyspad/private)에서 'SHIFTYPAD에 나의 니케 표시하기'를 '모두에게 공개'로 바꿉니다.
2. 블라블라링크에서 내 사진 → 내 홈으로 들어가 주소창 주소를 복사합니다. `https://www.blablalink.com/user?openid=...` 형태입니다.
3. 도우미의 '보유 니케' 탭에 붙여넣고 '가져오기'를 누릅니다.

이후로는 열 때마다 6시간 간격으로 알아서 다시 가져옵니다. 바로 반영하려면 위쪽 '내 정보 새로고침'을 누르면 됩니다.

## 탭별 기능

**니케 도감** — 전체 니케 목록. 이름, 영문명, 별명(흑련, 레후, 애헬름 등), 묶음(에게리, 체소맨, 수영복 등), 스쿼드, 기업으로 검색됩니다. 니케를 누르면 추천 큐브, 오버로드 옵션, 스킬 가성비/종결 레벨, 같이 쓰는 덱, 아레나 역할이 나옵니다.

**보유 니케** — 가진 니케 체크와 계정 가져오기. 이름/전투력/스킬/보스전 평가 순으로 정렬할 수 있고, 먼저 키울 니케와 스킨 개수도 보여줍니다.

**오버로드 계산기** — 니케를 고르면 맨 위에 종결·준종결·타협·부족 등급이 나오고, 장비 4부위 옵션과 합계, 부위마다 완성/잠그고 돌리기/다시 돌리기를 판정합니다. 니케별 세팅 포인트(목표 수치, 피할 옵션)가 있고 보스전/아레나 기준을 바꿀 수 있습니다.

**하모니 큐브** — 니케별 추천 큐브(보스전, 아레나)와 내 큐브 레벨, 먼저 올릴 큐브.

**티어표** — 버스트 단계별 티어표(보스전, 스토리, 아레나).

**레이드 덱** — 솔로 레이드, 유니온 레이드, 이상개체 요격전, 협동작전 보스별 추천 덱. 가진 니케로 덱을 자동으로 짜 주고 보스 코어 여부도 반영합니다. 솔로 레이드는 한국 서버 상위 50명이 실제로 쓴 덱과 사용률이 같이 나옵니다. 협동작전은 한 명씩 데려가는 방식이라 자리별로 내 니케 중 누구를 데려갈지 추천합니다.

**아레나** — 상대 덱을 넣으면 비슷한 메타 덱과 약점, 대응 니케를 보여줍니다. 요즘 많이 쓰는 공격/방어 덱, 내 니케로 짠 루키/스페셜/챔피언스 덱도 있습니다.

**캠페인** — 진행도와 다음 스테이지 권장 전투력 비교(노멀, 하드), 챕터별 보스와 데려갈 속성, 스토리 덱.

**레벨 계산기** — 레벨업에 필요한 크레디트, 배틀 데이터, 코어 더스트. 싱크로 레벨과 가진 재화가 자동으로 들어가고, 안 연 전초기지 케이스 개수를 넣으면 같이 계산합니다.

## 계정에서 가져오는 정보

| 정보 | 쓰이는 곳 |
|---|---|
| 보유 니케, 애장품 | 보유 니케, 레이드 덱, 아레나 |
| 장비 오버로드 옵션 | 오버로드 계산기 |
| 큐브 레벨, 스킬 레벨 | 하모니 큐브, 오버로드 계산기, 도감, 보유 니케 정렬 |
| 전투력, 캠페인 진행도 | 캠페인, 오버로드 계산기, 보유 니케 정렬 |
| 싱크로 레벨, 재화, 전초기지 레벨 | 레벨 계산기 |
| 스킨 | 보유 니케, 도감 |

## 참고

- 니케 목록을 공개하면 프로필 링크를 아는 사람은 내 니케와 장비를 볼 수 있습니다.
- 계정 정보는 비공식 서버인 [nikke-api](https://github.com/leegunwoooo/nikke-api)를 거쳐 가져옵니다. 서버가 안 될 때는 '보유 니케' 탭의 북마크 방식으로 가져올 수 있습니다.
- 가져온 정보는 각자 브라우저에만 저장됩니다. 다른 기기에서는 링크를 한 번 더 넣어야 합니다.
- 링크로 가져온 장비는 빈 옵션 줄 위치를 알 수 없어서, 옵션이 1~2줄이면 위에서부터 채워서 보여줍니다.
- 추천 내용은 Prydwen과 국내 커뮤니티(디시, 아카라이브, 에펨코리아) 공략을 정리한 것이라 참고용입니다.
