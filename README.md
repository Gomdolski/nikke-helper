# 니케 지휘관 도우미

승리의 여신: 니케 비공식 팬 도구예요. 설치 없이 브라우저에서 바로 열면 돼요.

**바로 열기: https://gomdolski.github.io/nikke-helper/**

새 버전이 올라오면 페이지 위쪽에 알림이 떠요. 무엇이 바뀌었는지는 도감 위 ‘이번 주 바뀐 점’ 상자에서 볼 수 있어요. 매주 금요일(니케 업데이트 다음 날)에 데이터를 확인해서 올려요.

---

## 처음 한 번만 해두면 되는 것

내 계정 정보(보유 니케, 장비, 큐브)를 가져오려면 아래 두 가지를 해두세요.

1. **ShiftyPad에서 니케 목록 공개하기**
   [ShiftyPad 숨김 설정](https://www.blablalink.com/setting/shiftyspad/private)에서
   **‘SHIFTYPAD에 나의 니케 표시하기’** 를 **‘모두에게 공개’** 로 바꿔요.
   비공개면 가져올 수 없어요.
2. **내 프로필 링크 복사하기**
   블라블라링크 오른쪽 위 내 사진을 눌러 **내 홈** 을 열고, 주소창의 주소를 복사해요.
   `https://www.blablalink.com/user?openid=…` 처럼 생겼어요.

## 가져오기

1. 도우미의 **‘보유 니케’** 탭을 열어요.
2. **‘내 블라블라링크 프로필 링크’** 칸에 복사한 주소를 붙여넣고 **‘가져오기’** 를 눌러요.
3. 링크는 브라우저에 저장돼요. 다음부터는 **페이지를 열기만 하면** 알아서 최신 정보로 바뀌어요(6시간마다). 게임에서 키운 걸 바로 보고 싶으면 맨 위 **‘↻ 내 정보 새로고침’** 을 누르세요. 어느 탭에서든 눌러도 돼요.

한 번 누르면 아래가 같이 들어와요.

| 가져오는 것 | 어디서 보나요 |
|---|---|
| 보유 니케 전체 | 보유 니케, 레이드 덱 |
| 애장품 보유 여부 | 보유 니케, 레이드 덱 |
| 장비 4부위(머리·몸통·팔·다리) 오버로드 옵션과 단계 | 오버로드 계산기 |
| 하모니 큐브 레벨 | 하모니 큐브 |
| 캠페인 진행도·스쿼드 전투력·니케별 전투력 | 캠페인 |
| 싱크로 레벨, 가진 크레딧·배틀 데이터·코어 더스트 | 레벨 계산기 |
| 스킨 개수, 니케마다 입은 스킨 | 보유 니케, 니케 도감(이름 누르기) |

## 탭별로 보여주는 것

| 탭 | 보여주는 것 |
|---|---|
| **니케 도감** | 전체 니케 목록(초상화 포함)과 검색. 한글·영문 이름은 물론 커뮤니티 별명(흑련, 레후, 애헬름, 수로시 등)으로도 찾을 수 있어요. 에게리·체소맨·리제로 같은 콜라보, 수영복·크리스마스, 스쿼드(카운터스 등)·기업 이름으로 치면 해당 니케가 모두 나와요. 누르면 추천 큐브, 오버로드 옵션, 스킬 레벨, 같이 쓰는 덱이 나와요. |
| **보유 니케** | 가진 니케 체크, 계정에서 가져오기, 먼저 키우면 좋은 니케. |
| **오버로드 계산기** | 니케를 고르면 장비 4개의 옵션과 **4개 합계**(우월코드·공격력 줄 수와 %)를 보여줘요. 장비마다 ‘완성 / 잠그고 돌리기 / 다시 돌리기’를 알려주고, 새로 돌린 옵션은 그 칸만 바꿔 보면 돼요. 흑련·앨리스·프리바티(애장품)·크라운 등 31명은 니케별 메모(목표 수치, 피해야 할 옵션, 버프가 자기 공격력에 비례하는지)도 나와요. ‘보스전/아레나’를 바꾸면 아레나 기준(차지 속도·장탄으로 버스트 선점, 우월코드보다 공격력)으로 판정해요. |
| **하모니 큐브** | 니케별 추천 큐브, 내 니케 기준 먼저 올릴 큐브, 내 큐브 레벨. |
| **티어표** | 버스트 I·II·III별 티어표 (보스전·스토리·아레나 기준). |
| **레이드 덱** | 솔로 레이드·유니온 레이드·이상개체 요격전 보스별 추천 덱과, 가진 니케로 자동 편성. 코어 유무도 반영해요. 솔로 레이드는 한국 서버 상위 50명이 실제로 쓴 덱 조합과 니케 사용률도 보여줘요. |
| **아레나** | 상대 덱을 슬롯 순서대로 넣으면 비슷한 메타 덱과 약점, 대응법, 추천 니케를 보여줘요. 요즘 많이 쓰는 공격·방어 덱(가진 니케로 되는 덱만 보기 가능), 내 니케로 짜는 루키·스페셜·챔피언스 덱, 아레나 기본 규칙. |
| **캠페인** | 내 진행도와 다음 스테이지 권장 전투력 비교(노멀·하드), 챕터별 보스와 데려갈 속성, 가진 니케로 짜는 스토리 덱, 막힐 때 팁. |
| **레벨 계산기** | 레벨업에 드는 크레딧·배틀 데이터·코어 더스트. 계정을 가져왔다면 지금 싱크로 레벨과 가진 재화가 자동으로 들어가서, 몇 레벨까지 올릴 수 있는지와 모자란 양을 보여줘요. |

## 알아둘 점

- **공개 범위:** 니케 목록을 공개로 두면, 내 프로필 링크를 아는 사람은 누구나 내 니케와 장비를 볼 수 있어요.
- **비공식 서버를 거쳐요:** 계정 정보는 비공식 공개 서버 [nikke-api](https://github.com/leegunwoooo/nikke-api)를 통해 가져와요. 그 서버가 멈추면 가져오기도 안 돼요. 그럴 땐 ‘보유 니케’ 탭의 **‘다른 방법: 북마크로 가져오기’** 를 쓰세요.
- **빈 옵션 줄 위치:** 링크로 가져온 장비는 비어 있는 옵션 줄의 위치를 몰라요. 그래서 옵션이 1~2줄인 장비는 위에서부터 채워 보여줘요.
- **저장 위치:** 보유 목록, 장비, 큐브 레벨은 각자 브라우저에만 저장되고 다른 곳에 올라가지 않아요. 브라우저 기록을 지워도 링크만 남아 있으면 열 때 다시 채워져요. 다른 브라우저나 기기에서는 링크를 한 번 더 넣으면 돼요.
- **스킨:** 가진 스킨 개수와 니케마다 지금 입은 스킨만 알 수 있어요. 가진 스킨 전체 목록은 공식 데이터에 없어요.
- **추천의 근거:** 평가와 추천은 Prydwen과 국내 커뮤니티(디시·아카라이브·에펨코리아) 공략을 요약한 거예요. 정답이 아니라 참고용이에요.

## 고치는 법 (만드는 사람용)

1. `build/` 안의 파일을 고쳐요 (`page.html` 화면, `raid_section.js` 덱 짜기, `*.json` 데이터).
2. `node build/build.js --note "바뀐 점"` 을 실행해요. `index.html`, `version.json` 이 새로 만들어져요.
3. 커밋하고 푸시하면 몇 분 안에 웹 주소에 반영돼요. 주간 업데이트 순서는 [UPDATE.md](UPDATE.md)에 있어요.
