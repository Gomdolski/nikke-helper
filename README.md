# 니케 지휘관 도우미

승리의 여신: 니케 비공식 팬 도구예요. 설치 없이 브라우저에서 바로 써요.

### 👉 [바로 열기: gomdolski.github.io/nikke-helper](https://gomdolski.github.io/nikke-helper/)

- 매주 **금요일**(니케 업데이트 다음 날)에 데이터를 새로 올려요.
- 새 버전이 나오면 페이지 위쪽에 알림이 떠요. 바뀐 내용은 도감 위 **‘이번 주 바뀐 점’** 에 있어요.

---

## 시작하기 (3분)

내 계정을 연결하면 보유 니케, 장비, 큐브, 전투력이 자동으로 채워져요.

**1. 니케 목록 공개하기** (처음 한 번)
[ShiftyPad 숨김 설정](https://www.blablalink.com/setting/shiftyspad/private) → **‘SHIFTYPAD에 나의 니케 표시하기’** 를 **‘모두에게 공개’** 로

**2. 내 프로필 링크 복사하기** (처음 한 번)
블라블라링크 오른쪽 위 내 사진 → **내 홈** → 주소창 주소 복사
`https://www.blablalink.com/user?openid=…` 처럼 생겼어요.

**3. 붙여넣고 가져오기**
도우미 **‘보유 니케’** 탭 → 링크 붙여넣기 → **‘가져오기’**

> 다음부터는 **열기만 하면** 알아서 최신으로 바뀌어요(6시간마다).
> 바로 바꾸고 싶으면 맨 위 **‘↻ 내 정보 새로고침’** 을 누르세요.

## 탭 안내

### 📖 니케 도감
- 전체 니케 목록 (초상화 포함)
- **검색:** 이름, 영문, 별명(흑련·레후·애헬름), 묶음(에게리·체소맨·수영복), 스쿼드, 기업
- **니케를 누르면:** 추천 큐브, 오버로드 옵션, **스킬 추천(가성비·종결)**, 같이 쓰는 덱, 아레나 역할

### ✅ 보유 니케
- 가진 니케 체크, 계정 가져오기
- 먼저 키우면 좋은 니케, 스킨 개수

### ⚙️ 오버로드 계산기
- 니케를 고르면 **장비 4개 + 합계**가 한눈에 보여요
- 장비마다 **완성 / 잠그고 돌리기 / 다시 돌리기** 판정
- 니케별 **세팅 포인트** (목표 수치, 피해야 할 옵션)
- **보스전 / 아레나** 기준 전환

### 🧊 하모니 큐브
- 니케별 추천 큐브 (보스전·아레나)
- 내 니케 기준으로 먼저 올릴 큐브, 내 큐브 레벨

### 📊 티어표
- 버스트 I · II · III 별 티어표 (보스전 · 스토리 · 아레나)

### ⚔️ 레이드 덱
- 솔로 레이드 · 유니온 레이드 · 이상개체 요격전 보스별 추천 덱
- **가진 니케로 자동 편성**, 보스 코어 여부 반영
- 솔로 레이드는 **한국 서버 상위 50명이 실제로 쓴 덱**과 사용률

### 🏟️ 아레나
- **상대 덱을 넣으면** 비슷한 메타 덱 · 약점 · 대응법 · 추천 니케
- 요즘 많이 쓰는 공격 · 방어 덱
- 내 니케로 루키 · 스페셜 · 챔피언스 덱 편성

### 🗺️ 캠페인
- 내 진행도와 다음 스테이지 **권장 전투력** 비교 (노멀 · 하드)
- 챕터별 보스와 데려갈 속성, 스토리 덱, 막힐 때 팁

### 📈 레벨 계산기
- 레벨업에 드는 크레디트 · 배틀 데이터 · 코어 더스트
- 내 싱크로 레벨과 가진 재화가 자동으로 들어가요
- **안 연 케이스** 개수를 넣으면 같이 계산해요

## 알아둘 점

- 🔓 **공개 범위:** 니케 목록을 공개하면, 내 프로필 링크를 아는 사람은 내 니케와 장비를 볼 수 있어요.
- 🌐 **비공식 서버:** 계정 정보는 [nikke-api](https://github.com/leegunwoooo/nikke-api)를 거쳐 가져와요. 서버가 멈추면 ‘보유 니케’ 탭의 **북마크로 가져오기**를 쓰세요.
- 💾 **저장 위치:** 내 정보는 각자 브라우저에만 저장돼요. 다른 기기에서는 링크를 한 번 더 넣으면 돼요.
- 🧩 **빈 옵션 줄:** 링크로 가져온 장비는 빈 줄 위치를 몰라서, 1~2줄짜리는 위에서부터 채워 보여줘요.
- 💡 **추천은 참고용:** Prydwen과 국내 커뮤니티(디시 · 아카라이브 · 에펨코리아) 공략을 요약한 거예요.
